# Production Deployment Checklist for Owner / Ops Team

## Pre-Deployment Verification

### 1. Environment Check ✅
- [ ] PHP 8.2+ installed
- [ ] Composer installed
- [ ] Node.js LTS + npm installed
- [ ] MySQL 8.0.16+ or MariaDB 10.6+ running
- [ ] Database `rentara` created

### 2. Backup Strategy (MANDATORY)
```bash
# Create timestamped backup
TIMESTAMP=$(date +%Y%m%d_%H%M%S)
mysqldump -u root rentara > backup_rentara_$TIMESTAMP.sql

# Verify backup size
ls -lh backup_rentara_$TIMESTAMP.sql

# Store backup securely
cp backup_rentara_$TIMESTAMP.sql /secure/backup/location/
```

### 3. Production Environment Variables
Set di hosting control panel atau `.env` file:

```dotenv
APP_NAME=Rentara
APP_ENV=production
APP_KEY= # Generate with: php artisan key:generate
APP_DEBUG=false
APP_URL=https://your-domain.com

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=rentara
DB_USERNAME=production_user
DB_PASSWORD=**SECRET**

# Brand configuration
APP_BRAND_NAME=Rentara
APP_BRAND_TAGLINE="Kelola properti. Temukan hunian."
APP_SUPPORT_EMAIL=support@your-domain.com

# Mail (for password reset, verification)
MAIL_MAILER=smtp
MAIL_HOST=your-mail-host
MAIL_PORT=587
MAIL_USERNAME=**
MAIL_PASSWORD=**
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=noreply@your-domain.com
MAIL_FROM_NAME="Rentara"
```

## Deployment Steps

### Step 1: Build Assets
```bash
npm install
npm run build
php artisan optimize
```

### Step 2: Upload Files
Deploy:
- `/app/`
- `/bootstrap/`
- `/config/`
- `/database/`
- `/public/build/` (from npm run build)
- `/resources/`
- `/routes/`
- `/storage/` (writable)
- `/vendor/`
- `artisan`
- `composer.json`
- `composer.lock`
- `phpunit.xml`

### Step 3: Set Web Root
Configure web server document root to:
```
/public/
```

### Step 4: Database Migration (PRODUCTION)
```bash
php artisan migrate --force
```

### Step 5: File Permissions
```bash
chmod -R 755 storage/
chmod -R 755 bootstrap/cache/
```

### Step 6: Queue/Schedule (Optional)
```bash
# For billing reminders, etc.
crontab -e
* * * * * cd /path/to/project && php artisan schedule:run >> /dev/null 2>&1
```

## Rollback Procedure

If deployment fails:
```bash
# Restore database from backup
mysql -u root rentara < backup_rentara_YYYYMMDD_HHMMSS.sql

# Rollback migrations (if needed)
php artisan migrate:rollback --step=1
```
